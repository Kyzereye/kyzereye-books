## Rules

- Only the book in a myLife finish slot gets regular work. Ideas for parked books go in that book's `README.md` or in `myLife/ideas.md`.
- Each book folder holds its own outline, chapters, and research. Chapter files are numbered (`01-...md`).
- Puzzle books are a separate repo: `puzzle-books`.
